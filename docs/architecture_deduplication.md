# Дедупликация голосов

## Условия

- Голосование анонимное, без регистрации. Окно ≈ 60 секунд, аудитория ≈ 100M человек по всему миру.
- Защищаемся от обычного пользователя. **Он умеет открыть инкогнито и включить или переключить VPN.**
- **Решение автора (в спецификации его нет):** голоса через VPN и с IP дата-центров принимаем. Там, где сервис заблокирован, до него доберутся только через VPN. В режиме белых списков в России VPN выходит через разрешённые российские облака, поэтому тысячи людей сидят за немногими IP.
- Засчитывается **первый** голос браузера (`voter_id`).

## Признаки

| Признак | Что даёт | Ограничение |
|---|---|---|
| Cookie + localStorage (`voter_id`) | Честный человек не проголосует дважды случайно | Обнуляется в инкогнито и в другом браузере |
| IP | Показывает, где сидят люди | Один на многих (мобильный CGNAT, VPN, публичный Wi-Fi), легко меняется |
| Отпечаток браузера (свой) | Не меняется в инкогнито и при смене VPN | У одинаковых устройств одинаковый |

Состав отпечатка:

- **Android и десктоп:**
  - модель (`userAgentData.getHighEntropyValues`);
  - GPU (WebGL), canvas;
  - экран, язык, часовой пояс, пользовательские настройки (`prefers-*`, размер шрифта).
- **iOS 26 (Safari):**
  - в UA заморожена версия ОС;
  - canvas, WebGL и WebAudio зашумлены;
  - `hardwareConcurrency` случаен.

  Остаются класс модели по размеру экрана, версия Safari, язык, часовой пояс и пользовательские настройки. Поэтому группы одинаковых отпечатков здесь большие.

Отпечатка без IP мало: он склеил бы одинаковые устройства по всему миру. IP в ключе нужен для того, чтобы совпадения оставались в пределах одного адреса, а не для опознания человека.

## Схема

1. **Cookie `voter_id`:** один голос на браузер.
2. **Ключ «отпечаток + IP»:** засчитываем не больше `N(f, IP)` голосов на ключ.
3. **Потолок на IP:** 5000 голосов в минуту на IPv4-адрес, для IPv6 на префикс `/64`.

**Голоса сверх лимита сохраняются с пометкой, но в итог не входят.** Они нужны для статистики. Лимит проверяется в момент прихода голоса, уже засчитанный голос не отзывается.

### Редкость отпечатка `p(f)`

```
p(f) = (засчитано(f) + α·p₀) / (всего засчитано + α)
```

- **Считается только по засчитанным голосам**, в текущем и прошлых эфирах. Если учитывать и голоса сверх лимита, накрутчик сделал бы свой отпечаток «частым» и сам себе поднял бы лимит.
- **`p₀ = 2%`, `α = 1000`:** пока голосов нет, любой отпечаток считается частым. С ростом общего потока вклад априорной оценки тает: при 1M голосов отпечаток, которого не было, получает p = 2·10⁻⁵.

### Люди за IP `n(IP)`

Оцениваем по числу **разных** отпечатков `D`, пришедших с IP за текущий опрос: `n̂` — решение уравнения

```
D = Σ_f (1 − (1 − p(f))^n̂)
```

Функция монотонна по `n̂`, поэтому корень находим бисекцией. Корень существует, пока `D` меньше числа отпечатков с `p > 0`.

Накрутчик добавляет в `D` только свой один отпечаток, раздуть оценку он не может.

### Лимит `N`

Честных людей с отпечатком `f` за этим IP приближённо ~ Пуассон(λ), `λ = n(IP) · p(f)`:

```
N = 1 + Q_Poisson(λ; 0.9999)
```

| Людей за IP | p = 2% | p = 0.1% | p = 0.01% |
|---|---|---|---|
| 3 (дом) | 3 | 2 | 2 |
| 50 | 7 | 3 | 2 |
| 1000 (метро) | 40 | 7 | 4 |
| 3000 | 92 | 12 | 5 |

**Цена уровня 0.9999:** в лимит упирается не больше ~10⁻⁴ честных голосующих, то есть ~1000 человек на 10M.

### Потолок на IP: 5000 в минуту

Прикидка, сколько людей физически помещается за одним IPv4-адресом:
- **Мобильный CGNAT** выдаёт абоненту блок из 256–4096 портов. Значит, на адрес приходится не больше ~256 абонентов.
- **NAT без блоков портов** (VPN, публичный Wi-Fi): 65 535 портов / 20–50 соединений на телефон ≈ 1300–3300 устройств.

Потолок 5000 взят с запасом. Число соединений на телефон — допущение: если их меньше, устройств за адресом помещается больше, и потолок нужно поднять.

Модель от страны не зависит: доля iPhone (≈29% в мире, ≈60% в США и Японии) автоматически отражается в `p(f)`.

## Пределы защиты

Точной дедупликации без входа при инкогнито и VPN не бывает. Схема **ограничивает** повторы.

| Способ повтора | Цена | Сколько лишних голосов |
|---|---|---|
| Новое окно инкогнито | ≈ 5–10 с | Пока у ключа есть запас (`N − 1 − λ`): дома 1–2, частый отпечаток в метро ≈ 19 |
| Смена VPN-сервера | ≈ 15–20 с | Новый ключ со своим запасом |

За 60 секунд эфира один человек успевает сделать **не больше ~10 лишних голосов**, в обычном домашнем случае 1–2.

**Известное ограничение:** смена пользовательских настроек (тема, размер шрифта) даёт новый отпечаток. Для обычного пользователя это неочевидно, и именно эти настройки делают отпечаток точнее.

## Данные и наблюдаемость

- IP хранится только в виде хэша с солью опроса. Счётчики заводятся на каждый опрос и удаляются через TTL после закрытия. В админке видны только агрегаты.
- Метрики: доля голосов сверх лимита по опросу и её всплески. Резкий рост означает, что `p(f)` откалиброван неверно или идёт накрутка.
