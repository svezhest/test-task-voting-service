# API и модель данных

## Типы вопросов

| Тип | Что выбирает зритель | Примеры |
|---|---|---|
| `single` | Ровно один вариант | А/Б, «да / нет», шкала с вариантами от админа |
| `multi` | Один или несколько вариантов | «Что из этого вы смотрите?» |

Вариантов не больше 64: столько помещается в битовую маску записи. Сколько показывать на экране, решает продукт. Для ТВ разумно 2–4.

## Жизненный цикл опроса

```
draft ──activate──► active ──конец окна + допуск──► counting ──► final
```

- `draft`: опрос можно редактировать.
- `active`: конфиг опубликован на CDN, приём принимает голоса в окне. Менять опрос нельзя.
- `counting`: окно закрыто, идут этап 1 и этап 2.
- `final`: итог окончательный.

## Публичный API

Страница и API на одном домене, CDN проксирует `/api`.

**`GET /p/{poll_id}`** — страница опроса (статика).

**`GET /p/{poll_id}/config.json`** — вопрос, тип, варианты, окно (статика, публикуется при активации).

**`POST /api/vote`**

```json
{
  "poll_id": "3f6c…",
  "options": [2],
  "voter_id": "b1e0…",
  "fp": { "…": "компоненты отпечатка" }
}
```

| Ответ | Когда |
|---|---|
| `204` | Голос записан в Kafka. Ответ одинаковый и для первого голоса, и для повтора: дедупликация идёт позже и наружу не видна. |
| `400` | Нет `voter_id` или неверный формат. |
| `404` | Опрос не найден или не активен. |
| `410` | Окно закрыто. |
| `422` | Неверные варианты: вне списка или несколько вариантов у `single`. |
| `503` | Приём перегружен, клиент повторяет с задержкой. |

Хэш отпечатка считает узел приёма, а не клиент: так формат и состав отпечатка под нашим контролем.

## Админка

Все запросы с заголовком `Authorization: Bearer <токен>`.

| Запрос | Что делает |
|---|---|
| `POST /admin/polls` | Создать опрос (`draft`): вопрос, тип, варианты, начало и конец окна, допуск. |
| `PATCH /admin/polls/{id}` | Изменить опрос, только в `draft`. |
| `POST /admin/polls/{id}/activate` | Перевести в `active`, опубликовать конфиг. |
| `GET /admin/polls` | Список опросов. |
| `GET /admin/polls/{id}/results` | Итоги. |

Итоги в `active` — только `received` (сколько голосов принято), без распределения по вариантам. В `final` — полный ответ:

```json
{
  "status": "final",
  "received": 25000000,
  "counted": 24100000,
  "over_limit_share": 0.036,
  "options": [
    { "idx": 0, "label": "Да",  "counted": 15000000, "total": 15600000, "share": 0.622 },
    { "idx": 1, "label": "Нет", "counted": 9100000,  "total": 9400000,  "share": 0.378 }
  ]
}
```

- `counted` — засчитанные голоса, `total` — все, включая голоса сверх лимита.
- `share` считается от засчитанных.

## Postgres

```
polls          (id uuid PK, question, type, status, window_start, window_end, grace_s,
                salt bytea NULL, config_version, created_at)
options        (poll_id, idx smallint, label,                       PK (poll_id, idx))
results        (poll_id, partition, option_idx, counted, total, last_offset,
                                                                    PK (poll_id, partition, option_idx))
stage_progress (poll_id, stage, partition, end_offset, done_at,     PK (poll_id, stage, partition))
fp_counts      (poll_id, partition, blob bytea,                     PK (poll_id, partition))
```

- `salt` — секретная соль для `HMAC(IP)`. Обнуляется после закрытия окна.
- `results` обновляется, только если `last_offset` больше сохранённого.
- `fp_counts` — блоки `c(f)` для слияния между проходами этапа 2. Глобальный блок хранится с `partition = -1`.

## Запись в Kafka

Бинарная, фиксированного размера, little-endian:

| Поле | Байт | |
|---|---|---|
| `version` | 1 | Версия формата, сейчас 1 |
| `poll_id` | 16 | UUID |
| `options` | 8 | Битовая маска вариантов |
| `received_at` | 8 | Время приёма, мс |
| `ip_hmac` | 16 | HMAC-SHA256(IP или префикс `/64`, соль опроса), первые 16 байт |
| `fp_hash` | 8 | Хэш стабильных компонентов отпечатка |
| `voter_id` | 16 | UUID |

Итого 73 Б, с накладными расходами Kafka ≈ 100 Б. JSON занял бы ~300 Б.

Топики:
- `votes_raw` — ключ `voter_id`, туда пишет приём;
- `votes_by_ip` — ключ `ip_hmac`, туда пишет этап 1.

Число партиций фиксируется до опроса.
